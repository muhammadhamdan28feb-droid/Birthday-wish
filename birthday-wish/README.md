# Birthday Wish Website

This project is a static birthday wish experience designed for simple deployment on Vercel.

## Structure

- index.html — main page markup
- css/style.css — all styling and animation rules
- js/script.js — all interactive behavior and content logic
- assets/images/ — image assets (currently empty)
- assets/audio/ — audio assets (currently empty)
- assets/icons/ — icon assets (currently empty)

## Deployment

Deploy the folder directly to Vercel as a static site. No build step is required.
